## Descripción

Portfolio personal desarrollado como continuación del TP1. Es una aplicación
multipágina que permite navegar entre Inicio, Sobre mí, Habilidades, Proyectos y
Contacto sin recargar el sitio.

El proyecto practica componentes reutilizables, comunicación mediante props,
renderizado dinámico con arrays y `map()`, navegación con React Router DOM y
estado interactivo con `useState`.

## Tecnologías

- React y JavaScript (JSX)
- Vite
- React Router DOM
- CSS
